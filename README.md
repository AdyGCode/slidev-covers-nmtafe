
# Slidev Covers – GitHub Pages Edition

Faculty‑safe approved Slidev background service using GitHub Pages.

## Setup
```bash
git clone <repo>
npm install
```

## Test
```bash
npm test
```

## Run Locally
```bash
npx serve docs
```

## Deploy
Enable GitHub Pages on `/docs` from main branch.

## Slidev Usage
```yaml
background: https://adygcode.github.io/slidev-covers-nmtafe/
```
